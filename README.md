# Primus Icon Library — Static Assets

zeroheight "İkonografi" sayfasındaki Code Block'lar için paylaşılan CSS ve ikon SVG'leri.
Kaynak: Figma "Primus DS - Icon Library" (fileKey `LFpvy1kI0thRGPrF2D3z6K`), node `8166:3479` (Icon Gallery).

## Paylaşılan CSS

zeroheight → Settings → Code → Shared resources → CSS alanına şu URL eklenir:

```
https://cdn.jsdelivr.net/gh/asilkandemirer/primus-icon-library@main/css/icon-gallery.css
```

Bu, tüm styleguide'daki code block'lara otomatik uygulanır. Sadece `.icon-page`, `.icon-section`,
`.icon-grid`, `.icon-card` gibi class'lar altında scoped olduğu için başka blokları etkilemez.

## İkon SVG'leri (opsiyonel, referans)

`icons/<kategori>/<isim>.svg` altında, her biri kendi kendine yeten (`width`/`height`/`fill` dahil) format.
