# Primus Icon Library — Static Assets

zeroheight "İkonografi" sayfasındaki Code Block için barındırılan gerçek ikon SVG'leri.
Kaynak: Figma "Primus DS - Icon Library" (fileKey `LFpvy1kI0thRGPrF2D3z6K`), node `8166:3479` (Icon Gallery).

## Kullanım

Her dosya jsDelivr üzerinden CDN URL'i ile çekilebilir:

```
https://cdn.jsdelivr.net/gh/<user>/<repo>@main/icons/<kategori>/<isim>.svg
```

Örnek:
```
https://cdn.jsdelivr.net/gh/<user>/primus-icon-library@main/icons/arrows-and-direction/arrow-down.svg
```
